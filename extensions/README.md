# 中文程 (ZhongCheng) — TurboWarp 官方扩展

[中文程](https://github.com/your-org/zhongcheng) 是一个自研的中文编程语言，本扩展将其完整的语言内核（词法分析器、语法分析器、异步解释器、标准库）直接内联到单个 JavaScript 文件中，实现**零依赖、零服务、完全离线运行**的 Scratch 3.0 / TurboWarp 扩展。

## 特性

- **三方言支持**：简体中文、繁体中文、拼音中文，自动识别或手动切换
- **完整语言内核**：变量、条件、循环、函数、类（面向对象）、列表、字典、闭包
- **内置标准库**：数学、文本、列表、字典、JSON、时间、绘图、文件、AI（线性回归/K均值聚类/神经网络）、系统、网络、IoT（TCP+MQTT）、智能家居（Home Assistant）、HTTP 服务端
- **舞台叠加画布**：独立 canvas 叠加在 Scratch 舞台之上，支持点/线/圆/矩形/弧/多边形/文字绘制
- **异步解释器**：不冻结 UI 界面，支持运行超时与停止
- **死循环保护**：每 5000 步让出事件循环 + 默认 30 秒超时
- **虚拟文件系统**：内存中的文件读写，无需真实文件系统
- **非沙盒运行**：画布叠加层、输入弹窗、DOM 访问需要非沙盒权限

## 方言说明

中文程支持三种方言，内核完全共享（同一套词法/语法/解释器），只是关键词和内置函数名不同：

| 方言 | 示例 |
|------|------|
| 简体 | `写("你好")` `设 x = 10` `如果 x > 5 则 ...` |
| 繁体 | `寫("你好")` `設 x = 10` `如果 x > 5 則 ...` |
| 拼音 | `xie("你好")` `she x = 10` `ruguo x > 5 ze ...` |

默认方言为"自动"，内核会在词法分析阶段对三种方言分别打分，选择命中关键词最多的方言。

## 加载方式

### 方式一：文件加载（推荐）

1. 打开 TurboWarp 编辑器
2. 点击「添加扩展」→「自定义扩展」→「文件」
3. 选择 `chineselang.js` 文件
4. **勾选「不使用沙盒运行」**（画布和输入功能需要 DOM 访问）

### 方式二：粘贴代码

1. 打开 TurboWarp 编辑器
2. 点击「添加扩展」→「自定义扩展」→「粘贴代码」
3. 将 `chineselang.js` 的全部内容粘贴进去

### 方式三：本地 HTTP 服务

```bash
npx http-server -p 8000
# 然后通过 URL 加载：http://127.0.0.1:8000/chineselang.js
```

> 注意：必须监听 `127.0.0.1:8000`，`localhost:8000` 或 `0.0.0.0:8000` 可能不被识别。

## 沙盒说明

本扩展需要 `unsandboxed: true`（非沙盒运行），原因如下：

- 画布叠加层需要直接操作 DOM（在舞台 canvas 上叠加独立 canvas）
- 输入弹窗使用自定义 DOM 元素（非 `window.prompt`，避免冻结线程）
- 舞台按钮需要 DOM 事件监听

非沙盒模式下所有积木均可正常使用。沙盒模式下，纯计算类积木（变量、数学、文本等）仍可工作，但画布、输入弹窗等功能会降级为中文提示。

## 技术细节

- **语言内核**：自研，包含方言词表、词法分析器、递归下降语法分析器、异步树遍历解释器、标准库
- **构建方式**：`build.js` 将 5 个内核文件（dialects / lexer / parser / interpreter / stdlib）合并为单文件
- **运行时**：纯 JavaScript，零第三方依赖，不含 Node 专有 API
- **CSP 兼容**：不使用 `eval()` / `new Function()`
- **异步安全**：解释器为异步树遍历，每 5000 步让出事件循环
